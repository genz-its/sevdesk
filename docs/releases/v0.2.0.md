# sevdesk v0.2.0

First GitHub release of the sevdesk SDK and CLI maintained at
[mi-skam/sevdesk](https://github.com/mi-skam/sevdesk), based on
[genz-its/sevdesk](https://github.com/genz-its/sevdesk). The upstream MIT license,
author attribution, and package/import names are retained. This is an independent
distribution, not a release published by the upstream maintainers.

## Install

Requires **Node.js 22+**. Account operations require sevdesk bookkeeping system 2.0.

```bash
npm install -g https://github.com/mi-skam/sevdesk/releases/download/v0.2.0/sevdesk-cli-0.2.0.tgz
sevdesk --version
```

The CLI asset bundles the matching SDK **0.2.0**. Other runtime dependencies are
installed from npm. No packages from this release are published to npm; installing
`@genz-its/sevdesk-cli` or `@genz-its/sevdesk-sdk` by registry name alone installs
the upstream distribution instead.

For SDK-only use:

```bash
npm install https://github.com/mi-skam/sevdesk/releases/download/v0.2.0/sevdesk-sdk-0.2.0.tgz
```

Imports remain `import { SevDesk } from '@genz-its/sevdesk-sdk'`.
Both archives are accompanied by `SHA256SUMS`.

## Highlights

- **Invoice drafts:** create regular draft invoices from validated JSON, partially
  update fields and contact addresses, replace all positions, and delete unsent drafts.
- **Invoice delivery:** send an existing unsent draft with explicit confirmation,
  number substitution, shared email validation, and a private operation receipt.
  Finalised/sent invoices are refused; uncertain outcomes never automatically retry.
- **Draft inspection:** `invoices:list --drafts`, client-side status enforcement,
  and duplicate invoice-number warnings naming the affected draft IDs.
- **Complete position reads:** use the paginated `/InvoicePos` resource rather than
  the invoice convenience endpoint, which can ignore offsets. Repeated pages and
  positions belonging to another invoice are rejected before replacement.
- **Quote workflows:** structured JSON, interactive editing, customer selection,
  positions, PDF previews, saving, sending, and recovery receipts.
- **Numbering:** inspect configured formats and suggest unused quote/invoice numbers,
  including existing drafts. Duplicate checks are not atomic reservations.
- **SDK:** partial invoice saves with explicit position deletion references,
  invoice deletion, and paginated invoice-position listing. The existing
  `positions` save option remains supported as an alias for `invoicePosSave`.

## Breaking changes and automation

- Primary files and target IDs are **positional**. For example:
  `sevdesk invoices:get 9001 --json` and
  `sevdesk invoices:create invoice.json --dry-run --json`.
  Removed target `--id`, `contacts:add-* --contact`, and voucher `--file` flags have
  no compatibility aliases. Relationship/filter options remain named options.
- `invoices:list --drafts --json` returns `{ invoices, warnings }`.
  Duplicate draft numbers also return that envelope without `--drafts`; other
  invoice list results retain the legacy array. Use `--drafts --json` for a stable
  draft-list envelope. Limits and filters restrict duplicate detection.
- Every command supports `--json`; exit codes remain 0/1. Invoice writes require
  `--yes` when non-interactive. Dry runs are offline and do not validate account IDs
  or stored document state.
- Finalised invoices are immutable (GoBD). Use a credit note or cancellation rather
  than trying to update/delete them. Email sending finalises a draft.

## Verification

The release workflow runs build, lint, typecheck, unit tests, and terminal tests,
then installs the generated SDK and CLI assets into isolated temporary directories.
It verifies the bundled SDK version, archive checksums, command availability, and
an offline invoice-update preview. It does not perform live bookkeeping writes.

See the [CLI reference](https://github.com/mi-skam/sevdesk/blob/v0.2.0/packages/cli/README.md)
and [SDK reference](https://github.com/mi-skam/sevdesk/blob/v0.2.0/packages/sdk/README.md).
